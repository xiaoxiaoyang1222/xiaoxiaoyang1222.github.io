# Zhengyang Li · Personal website

Static bilingual personal website for GitHub Pages. Includes education, ongoing research, selected challenge results, and a printable public résumé.

Publish this directory to `xiaoxiaoyang1222/xiaoxiaoyang1222.github.io`, then enable GitHub Pages from `main` / root. The site is served at `https://xiaoxiaoyang1222.github.io/`.

No build step or external dependencies. Edit `index.html` for content, `style.css` for styling, and `script.js` for the language switch. `cv.html` supports printing to PDF.
